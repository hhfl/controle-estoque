# Manual de Uso – Controle de Estoque

1. **Cadastre categorias** em *Categorias* (ex.: Bebidas, Limpeza). É obrigatório ter ao menos uma antes de criar produtos.
2. **Cadastre produtos** em *Produtos → Novo produto*. Informe nome, código (SKU único), preço, quantidade inicial, estoque mínimo e categoria.
3. **Registre movimentações** em *Movimentar*: escolha o produto, o tipo (Entrada para compras/reposição, Saída para vendas/baixas) e a quantidade.
4. **Acompanhe** o *Histórico* e o painel *Início*, que lista os produtos com estoque baixo (⚠️).
5. **Busque** produtos pelo campo de busca (nome ou código).
6. **Editar/Excluir** produtos na lista; a exclusão pede confirmação.

Dicas: use vírgula ou ponto no preço (12,50). O sistema avisa em vermelho quando algo está errado e em verde quando a ação deu certo.
